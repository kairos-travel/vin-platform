# Урок 08 — Гараж

**Цель:** раздел ЛК **«Гараж»** — сохранённые ТС; подстановка VIN/ГРЗ/СТС в корзину и заказ.

## Задание (сдать наставнику)

- [ ] **Шаг 1:** миграция `vehicles` — `profile_id`, `label` (название), `vin`, `grz`, `sts` (nullable), `timestamps`.
- [ ] **Шаг 2:** CRUD в ЛК: список, добавить, редактировать, удалить (Policy — только свои).
- [ ] **Шаг 3:** на странице оффера / в корзине — выбор «Из гаража» → подставить идентификатор.
- [ ] **Шаг 4:** опционально: после успешного отчёта предложить «Сохранить в гараж».
- [ ] **Шаг 5:** валидация форматов VIN/ГРЗ/СТС (Form Request).
- [ ] **Собес:** §15 (нормализация — что хранить в vehicles) — устно.
- [ ] `TIME_LOG`.

## Техника

### Модель

```php
// Vehicle: belongsTo Profile
// Profile: hasMany Vehicle
```

Не дублировать `vehicles` в `order_items` — в заказе остаётся **snapshot** `input_value` на момент покупки.

### UI

- `/account/garage` — таблица/карточки
- Модалка выбора ТС при добавлении в корзину

**Критерий:** ТС из гаража → корзина → заказ с правильным VIN в `order_items`.
