## Что добавится в пакете B

### Главная — 11 услуг (как в ТЗ)

- На главной — **карточки всех услуг** из базы (не только VIN)
- Услуги **без подключённого API** — пометка **«Скоро»**, без кнопки «Купить»
- **VIN** остаётся единственной **полностью рабочей** услугой
- Адаптив блока услуг на телефоне и планшете

### Гараж

- Клиент сохраняет **свои автомобили** (VIN, госномер, СТС, название)
- При заказе VIN — **подставить данные из гаража** одним кликом
- Не нужно каждый раз вводить номер заново

### Служба поддержки

- В личном кабинете — **создать обращение**, привязать к заказу
- Переписка с поддержкой в одном месте
- Статусы: открыт → ответ дан → закрыт

### Расширенная админ-панель

К **базовой админке из A** добавляется:

| Раздел | Что можно делать |
|--------|------------------|
| **Поддержка** | Видеть обращения клиентов, отвечать, менять статус |
| **Заказы (расширенно)** | Подробный просмотр: позиции, оплата, отчёты по заказу |
| **Отчёты — повтор** | Перезапустить формирование, если отчёт «упал» |
| **Журнал API** | Лог запросов к внешним сервисам по заказу (для разбора проблем) |

### Хранение PDF *(опционально)*

- Перенос PDF на **облако (S3)** и защищённые ссылки на скачивание  
- *Или оставить на сервере, как в A — по вашему решению*

## Сообщение для клиента (можно скопировать)

Добрый день!

**Пакет B** — следующий этап после MVP (пакет A). Включает **весь MVP** и добавляет то, что нужно для **полноценной витрины по ТЗ**.

**Что добавляется к MVP:**

- **Главная с 11 услугами** — все карточки на сайте; VIN работает полностью, остальные — «Скоро» *(+18 тыс. ₽)*
- **Гараж** — сохранённые автомобили, подстановка в заказ VIN *(+21 тыс. ₽)*
- **Поддержка** — обращения в ЛK + ответы в админке *(+36 тыс. ₽)*
- **Расширенная админка** — повтор «упавших» отчётов, журнал API, детальный просмотр заказов *(+24 тыс. ₽)*
- **S3 для PDF** *(опционально, +12 тыс. ₽)*

**Итого пакет B:** ~**261 час**, **~392 тыс. ₽** *(A + B)*, срок **~3 месяца** с начала проекта.

**Админка:** в A — каталог VIN и просмотр заказов; в B — **+ поддержка и операционные инструменты** для ежедневной работы.

**Не входит в B:** тарифы «N отчётов», три новых услуги с API (штрафы, ФССП, ЭПТС), pixel-perfect по Figma — это **пакет C**.
