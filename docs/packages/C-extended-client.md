## Что добавится в пакете C

### Тарифы — пакеты отчётов

Модель **согласована**:

- Клиент покупает **пакет N отчётов** на услугу (например, «5 VIN-отчётов»)
- **Без срока действия** — только количество
- **1 заказ = −1** отчёт из пакета
- Страница **`/tariffs`**, оплата через Paykeeper
- При оформлении: списать из пакета **или** оплатить полную цену

**В админке:** управление тарифными планами и остатками у клиентов.

### Три новых услуги с реальными отчётами

По умолчанию (можно заменить по согласованию):

| Услуга | Что получит клиент |
|--------|-------------------|
| **Штрафы ГИБДД** | Страница, заказ, live API, PDF |
| **Задолженности ФССП (физ.)** | То же |
| **ЭПТС** | То же |

Для каждой — своя цепочка API (как у VIN), управление в админке.

### Production-ready

- **Ручные возвраты** через админку (связка с Paykeeper)
- **Защита от перегрузки** (лимиты на webhook и формы)
- **Мониторинг** работоспособности сайта
- **Резервное копирование** базы и PDF
- **Инструкция** для эксплуатации (runbook)

### Pixel-perfect UI *(при макетах дизайнера)*

- **Точная вёрстка 1:1** с Figma (tablet + mobile) для новых страниц: гараж, поддержка, тарифы, 3 услуги
- **Полировка страниц MVP** под отдельные макеты, если дизайнер их отдаст
- *В A и B уже есть **адаптив** — здесь именно **совпадение с макетами***

## Сообщение для клиента (можно скопировать)

**Пакет C** — расширенный этап после A и B. Включает **весь предыдущий функционал** и добавляет монетизацию и новые услуги.

**Что добавляется к пакету B:**
