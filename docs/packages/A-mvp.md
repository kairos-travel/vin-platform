# Пакет A — MVP (запуск VIN)

**Цель:** одна услуга **VIN-отчёт** — корзина с несколькими офферами, **живые API**, реальный PDF.

| | |
|---|---|
| **Сумма** | **280 000 ₽** *(мин. объём)* |
| **Часы** | **187 ч** *(мин.)* |
| **Срок** | **~2 – 2,5 месяца** (20 ч/нед) |
| **Ставка** | 1 500 ₽/ч |

*Уже выполнено: VPS, ERD, staging, миграции. **Осталось:** HTTPS (+ доступ к DNS).*

*Техническая версия:* [A-mvp-client.md](./A-mvp-client.md) (для заказчика)

**Обновлено:** 2026-06 — scope: VIN, корзина, live API, **адаптив 9 страниц MVP**, ставка 1 500 ₽/ч.

### Корзина и checkout

> Общие термины: [README пакетов](./README.md#общие-правила-во-всех-пакетах-где-есть-корзина)

- [ ] **Checkout:** перенос корзины в заказ → один платёж Paykeeper на всю сумму

## Фронт: адаптив в пакете A

**Mobile + tablet** — проработанный responsive **по каждой странице MVP** (не «ломается на телефоне», а нормальная вёрстка под ширину экрана).

| Страница | Desktop | Mobile + tablet |
|----------|---------|-----------------|
| Главная (меню, hero, 1 услуга, форма, подвал) | ✓ | ✓ |
| VIN — офферы, цены, «В корзину» | ✓ | ✓ |
| Регистрация / вход | ✓ | ✓ |
| Корзина | ✓ | ✓ |
| Оформление заказа (checkout) | ✓ | ✓ |
| ЛК: профиль | ✓ | ✓ |
| ЛК: заказы | ✓ | ✓ |
| ЛК: отчёты | ✓ | ✓ |
| Политика конфиденциальности | ✓ | ✓ |

| Уровень | В пакете A? |
|---------|-------------|
| **Адаптив по страницам MVP** (таблица выше) | **Да** |
| **Pixel-perfect 1:1** по отдельным макетам tablet/mobile от дизайнера | **Нет** → пакет C (новые страницы B/C + полировка всего сайта) |
| Filament (админка) | стандартный responsive Filament |
