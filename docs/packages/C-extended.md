## Дополнительно к пакету B

### Тарифы — пакеты по количеству (урок 14)

Модель **согласована с заказчиком**:

- [ ] `tariff_plans.service_id` — тариф привязан к **услуге**
- [ ] Только **quota** (N отчётов). **Без тарифов по сроку.**
- [ ] Пример: «5 VIN-отчётов» → `profile_tariffs.reports_remaining = 5`
- [ ] **1 заказ = −1**; любой оффер этой услуги = **1** квота
- [ ] У **каждой** услуги может быть свой тариф-пакет
- [ ] Страница `/tariffs`, покупка через Paykeeper
- [ ] `TariffGate` при checkout: квота или полная цена
- [ ] Filament: `TariffPlan`, `ProfileTariff`

### Production-ready (урок 15)

- [ ] Ручные возвраты (Filament + Paykeeper)
- [ ] Rate limit: webhook, формы заказа
- [ ] Health `/up`, runbook, backup БД + PDF
- [ ] Cron: `depleted` при нуле квоты
