## Пакет A — MVP VIN (~280 тыс. ₽)

Первый рабочий запуск сайта: клиент регистрируется, кладёт **VIN-отчёты** в корзину, оплачивает картой через Paykeeper и получает **настоящий PDF** из внешних API. На сайте — **одна услуга VIN**, личный кабинет (профиль, заказы, отчёты), **адаптив** под телефон и планшет. **Базовая админка:** цены, варианты отчёта, цепочки API, просмотр заказов. Без остальных услуг, без тарифов «N отчётов», без гаража и без каталога запчастей.

---

## Пакет B — Рабочий продукт (~392 тыс. ₽)

**Включает A целиком** и добавляет витрину как в ТЗ: на главной **11 карточек услуг** (рабочей пока только VIN, остальные — «Скоро»). Появляются **гараж** (сохранённые авто), **служба поддержки** в личном кабинете и **расширенная админка** — ответы на обращения, повтор «упавших» отчётов, журнал запросов к API. Опционально — хранение PDF в облаке (S3).

---

## Пакет C — Расширенный (~608 тыс. ₽)

**Включает A и B целиком** и добавляет **тарифы «купи N отчётов заранее»**, **три новые услуги с live API** (по умолчанию: штрафы ГИБДД, ФССП, ЭПТС — итого **4 рабочие услуги**, не все 11), **production** (возвраты, backup, мониторинг) и **pixel-perfect вёрстку** по макетам дизайнера на tablet/mobile. В админке — тарифы, возвраты, настройка новых услуг. Каталог запчастей и оставшиеся услуги — **не входят**.

---

## Пакет D — Полное ТЗ (~974 тыс. ₽)

**Включает A, B и C целиком** и закрывает **весь объём ТЗ**: все **11 направлений** с рабочими отчётами, **заказ осмотра ТС**, **интернет-каталог запчастей** (админка, витрина, корзина, оплата — без импорта из 1С), тарифы на все активные услуги. Это финальная версия платформы «под ключ» по документу ТЗ.

---

## Что не входит ни в один пакет (отдельно)

- Дизайн макетов (desktop уже есть; tablet/mobile — для pixel-perfect в C)
- Абонплаты API-провайдеров, комиссия Paykeeper, хостинг VPS
- Импорт запчастей из 1С/Excel, интеграция со складом
- СБП / QR, DaData, публичное API для мобильного приложения

## Как выбрать

| Если нужно… | Пакет |
|-------------|-------|
| Быстро запустить продажу VIN и проверить спрос | **A** |
| Главная как в ТЗ + гараж + поддержка | **B** |
| Тарифы, ещё 3 услуги, prod-готовность | **C** |
| Всё по ТЗ, включая запчасти и все услуги | **D** |

**Рекомендуем начать с пакета A** — минимальный риск, рабочий продукт за ~2–2,5 месяца.
