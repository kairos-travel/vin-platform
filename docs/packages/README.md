## Общие правила (во всех пакетах, где есть корзина)
|--------|----------|
| **Одна корзина на профиль** | У каждого `Profile` — одна `Cart` (`profile_id` unique) |
| **Checkout** | `Cart` → `Order` + N `OrderItem` + **один** `Payment` на Paykeeper |
| **Snapshot цены** | `order_items.price_snapshot` — цена оффера **на момент оформления**, не меняется при смене цены в админке |
| **Оплата отчётов** | Только **«В корзину»** → `/cart` → оформление (без «Купить сейчас» в A; опционально в B+) |

## Решения заказчика (зафиксировано)

- Тариф = **пакет N отчётов**, привязан к **услуге**; **без** тарифов по сроку
- **1 заказ = −1** квота; любой VIN-offer = **1** единица
- Запчасти — CRUD в Filament, **без** импорта/выгрузки на старте
- Отчёты в ЛК — **1 год**
