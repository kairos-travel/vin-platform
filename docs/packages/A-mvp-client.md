## Что получите

### Сайт и вход

- Рабочий сайт на вашем домене (**https**, защищённое соединение)
- **Регистрация и вход** — без регистрации купить нельзя
- **Главная страница** по макету Figma (desktop) — меню, заголовок, **одна услуга VIN**, форма, подвал
- Страница VIN с **несколькими вариантами отчёта** (например, «Опция 1», «Опция 2») — разные цены и состав PDF
- **Адаптив под телефон и планшет** — на всех страницах MVP (см. список ниже)

### Адаптив — какие страницы

| Страница | На телефоне / планшете |
|----------|------------------------|
| Главная | ✓ |
| VIN (выбор отчёта) | ✓ |
| Регистрация / вход | ✓ |
| Корзина | ✓ |
| Оформление заказа | ✓ |
| Личный кабинет: профиль, заказы, отчёты | ✓ |
| Политика конфиденциальности | ✓ |

На телефоне можно **полностью пройти путь**: зайти → выбрать отчёт → оплатить → скачать PDF.

*Точное совпадение с отдельными макетами tablet/mobile от дизайнера (pixel-perfect) — в следующих этапах.*

### Корзина и оплата

- Кнопка **«В корзину»** — клиент может добавить **несколько VIN-отчётов** (разные опции, разные VIN / госномера / СТС)
- Страница **корзины** — проверить состав, удалить лишнее, увидеть итог
- **Одна оплата** на весь заказ через **Paykeeper** (банковская карта)
- Цена в заказе **фиксируется** — если потом измените цену в админке, старые заказы не «поплывут»

### Реальные отчёты (не демо)

- После оплаты система **запрашивает данные у внешних сервисов** (Tronk, API CLOUD и др. — по вашей схеме)
- Для **каждого варианта отчёта** — **своя цепочка запросов**
- Клиент получает **настоящий PDF** в личном кабинете
- Если часть данных недоступна — отчёт может быть **частичным**

### Личный кабинет

- **Профиль**, **заказы**, **отчёты** (скачивание PDF, хранение **1 год**)

### Админ-панель (пакет A)

Отдельный **вход для администратора** (Filament). В MVP — **базовая админка**, достаточная для запуска VIN без разработчика:

| Раздел | Что можно делать |
|--------|------------------|
| **Услуги** | Добавить / изменить услугу VIN, включить или выключить на сайте |
| **Варианты отчёта (офферы)** | Названия, цены, состав PDF («что входит в отчёт») |
| **Цепочки API** | Для каждого варианта — какие внешние сервисы вызывать и в каком порядке |
| **Заказы** | **Просмотр** — состав, сумма, статус оплаты, позиции (без редактирования сделки) |

**Пока нет в админке A** (следующие этапы):

| Функция | Пакет |
|---------|-------|
| Поддержка: тикеты, ответы клиентам | B |
| Повторный запуск «упавших» отчётов, журнал API-запросов | B |
| Тарифы «5 / 10 отчётов заранее» | C |
| Ручные возвраты | C |
| Управление запчастями | D |

### Юридическое и техническое

- **Политика конфиденциальности**, согласие ПДн при регистрации
- Базовые автотесты ключевого сценария (оплата)
- Инструкция по развёртыванию

## Что нужно от вас

**Доступы и сервисы**

- Домен **iz-agent.ru** и доступ к DNS (для HTTPS)
- VPS (уже есть) — при необходимости доступ для финальной настройки
- Кабинет **Paykeeper** — тестовый и боевой
- **API-ключи:** Tronk, API CLOUD, SpectrumData (и другие по вашей схеме)

**Контент и схема работы**

- **Таблица:** для каждого варианта VIN-отчёта — какие API вызывать и в каком порядке
- **Тестовые VIN / госномера / СТС** для проверки
- **Тексты и цены** для вариантов VIN-отчёта (названия, состав PDF)
- **Реквизиты компании** для политики конфиденциальности (152-ФЗ)

**Не входит в вашу поставку (отдельно)**

- Абонплаты API-провайдеров и Paykeeper (% с транзакций)
- Хостинг VPS (~500–1 500 ₽/мес)
- Дизайн **tablet/mobile** макетов (если понадобится pixel-perfect позже)

*Дизайн главной (desktop) — уже есть.*

## Интернет-каталог запчастей — будет ли в MVP?

**Нет.** В MVP — только **продажа VIN-отчётов**.

**Полноценный каталог запчастей** (как в ТЗ) заложен в **пакет D** (финальный этап):

- админка: добавление запчастей вручную (название, артикул, цена, фото)
- **витрина на сайте:** список, карточка, базовые фильтры
- **корзина и оплата** запчастей
- заказы запчастей в личном кабинете

**На старте каталога не будет:** без импорта из 1С/Excel, без интеграции со складом, без подбора по VIN из «Гаража» — это отдельные задачи позже.

Если каталог нужен **раньше**, чем весь пакет D — отдельным этапом после MVP (~**102 тыс. ₽**, 68 ч мин., 3–5 нед.).

Добрый день!

Сделал оценку для **MVP** (минимально жизнеспособный продукт) — это первый рабочий запуск сайта, где уже можно **продавать VIN-отчёты**: клиент регистрируется, кладёт отчёты в корзину, оплачивает и получает **настоящий PDF**.

**Что входит в MVP:**

- **Подготовка и сервер** — **осталось HTTPS** (домен, VPS, база данных, архитектура — **уже готовы**) *(~2–4 ч)*
