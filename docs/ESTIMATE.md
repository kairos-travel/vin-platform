## 2. Что входит / не входит

### Входит в оценку

- Backend: Laravel, БД, API-интеграции, очереди, Paykeeper, PDF
- Frontend: вёрстка по макетам (**когда отдаст дизайнер**), Blade + Tailwind
- Админка Filament (каталог услуг, **запчасти**, заказы, поддержка, тарифы)
- **Каталог запчастей:** CRUD в админке, витрина на сайте, покупка через корзину (без импорта/выгрузки)
- Личный кабинет (профиль, заказы, отчёты, гараж, поддержка)
- Аналитика: уточнения с заказчиком, фиксация в QUESTIONS/DOMAIN
- Базовая документация (README, runbook, политика ПДн — черновик)

### Не входит

| Исключено | Почему |
|-----------|--------|
| **Работа дизайнера** | Отдельный подрядчик: desktop / tablet / mobile |
| **Контент** | Тексты услуг, оферта, реквизиты оператора ПДн — даёт заказчик |
| **Абонплаты API** | Tronk, API CLOUD, Paykeeper, хостинг — расходы заказчика |
| **Страховки и подбор запчастей из «Гаража»** | В ТЗ §6.1 — «будущие возможности» |
| **Импорт / выгрузка каталога запчастей** | Позже; на старте только ручное создание в Filament |
| **Sanctum API для мобильного приложения** | Опционально, после MVP |

### Отдельной строкой (по запросу)

## 3. Объём по ТЗ vs план разработки

В [Сайт.docx](../../../Сайт.docx) — **11 основных функций**. Распределение по [пакетам](./packages/README.md):

| Пакет | Scope |
|-------|--------|
| **A** | Только **VIN**: корзина, live API, цепочка на оффер, без тарифов |
| **B** | A + **11 карточек** на главной, гараж, поддержка, ops |
| **C** | B + **тарифы (quota)**, +3 услуги, prod, pixel-perfect UI |
| **D** | C + все услуги, осмотр ТС, **запчасти** (CRUD админка) |

- **Тарифы:** пакеты N отчётов на **услугу**, без срока — [QUESTIONS.md](../QUESTIONS.md)
- **DaData** — не в первой версии
- **Оплата:** карта (Paykeeper); СБП позже
- **Запчасти:** пакет D; без импорта/выгрузки

## 7. Риски, влияющие на срок и сумму

| Риск | Влияние |
|------|---------|
| Нет ответа по тарифам/пакетам (§0) | +2–4 нед ожидания; этап 3 не стартует |
| API без документации / нестабильные ключи | +20–40% на интеграции (этап 2, 4) |
| Макеты ЛК с задержкой | Этап 3 сдвигается; MVP можно на базовом UI |
| Юридические требования к паспортным данным | Услуга «паспорт» — отдельное согласование, +8–16 ч |
| Импорт запчастей понадобится раньше срока | +24–40 ч (этап 6) |
| Запчасти и отчёты в одном заказе vs раздельно | +8–16 ч на доработку checkout |

## 8. Условия оценки

- Ставка: **1 500 ₽/ч**, без НДС (уточнить статус ИП/самозанятости отдельно)
- Оплата: по этапам (предоплата 30% этапа → акт → следующий этап)
- Неучтённое время: изменения ТЗ >4 ч — отдельная согласованная задача
- Гарантия на исправление дефектов по принятому этапу: **14 дней** после сдачи
